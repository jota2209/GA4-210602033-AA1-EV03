\section{Soportes para la evidencia}
Los insumos de interés que soportan la evidencia tales como scripts ddl, diagramas entidad relación y ficheros YAML para despliegue de los contenedores docker se pueden encontrar en el siguiente repositorio de GitHub:

\vspace{0.5cm}
\begin{center}
	\href{https://github.com/jota2209/GA4-210602033-AA1-EV03}{→ Click aquí para acceder al repositorio ←}
	
\end{center}
\vspace{0.5cm}

\begin{itemize}
	\item \textbf{Diagrama Entidad Relación:} El diagrama entidad relación puede verse de forma interactiva mediante \texttt{erd\_springvalley.html} o de forma estática mediante \texttt{erd\_\allowbreak springvalley.html}, \texttt{springvalley.pgerd} es el archivo nativo producido por pgadmin que muestra el modelo de la base de datos este último puede abrirse si se tiene pgadmin instalado.
	
	\item \textbf{Script SQL y Sentencias DDL:} Si bien la base de datos se implementa mediante bash scripting, se aislaron las sentencias SQL necesarias para la mera generación de las tablas y sus respectivas relaciones el fichero correspondiente al script SQL es \texttt{ddl.sql}
\end{itemize}
